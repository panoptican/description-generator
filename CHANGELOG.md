# Changelog

## Version 3 — 2026-09-15

### Changed

- Free plans now use credits: text-only requests cost 1 credit; requests containing an image cost 2. Pro image requests remain 1 monthly description.
- Reduced the plugin window width from 675px to 608px for a more compact layout.
- Updated usage messaging throughout the interface to explain credit costs.

### Fixed

- Icon mode can now be turned back on after being disabled for a detected icon.
- Failed image generations restore the full two-credit reservation.
